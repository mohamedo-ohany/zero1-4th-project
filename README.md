## 🌟 Overview

Zero1 Dashboard is a clean, modern, and fully responsive admin dashboard template designed with pure HTML and CSS. It features a comprehensive set of pages and components commonly needed in admin panels, including user management, project tracking, file management, and analytics displays.

### Key Highlights

- 🎨 **Clean & Modern Design** - Professional UI with smooth animations
- 📱 **Fully Responsive** - Works seamlessly on desktop, tablet, and mobile devices
- ⚡ **Pure HTML/CSS** - No JavaScript dependencies, lightweight and fast
- 🎯 **Production Ready** - Well-structured code, easy to customize
- 🔧 **Modular Components** - Reusable UI elements throughout the project

## 🛠 Technologies Used

### Front-End

- **HTML5** - Semantic markup structure
- **CSS3** - Modern styling with:
  - CSS Grid & Flexbox for layouts
  - CSS Custom Properties (variables)
  - Media queries for responsiveness
  - Smooth animations and transitions

### External Libraries

- **[Font Awesome 6](https://fontawesome.com/)** - Icon library
- **[Google Fonts - Open Sans](https://fonts.google.com/specimen/Open+Sans)** - Typography
- **[Google Fonts - Cairo](https://fonts.google.com/specimen/Cairo)** - Additional typography

### CSS Framework

The project includes a custom CSS framework (`framework.css`) with utility classes for:
- Display properties (`dis-f`, `dis-g`, `dis-b`)
- Positioning (`pos-r`, `pos-a`)
- Flexbox utilities (`js`, `ac`, `ae`, `f-d`, `f-w`)
- Spacing (`p-*`, `m-*`, `gap-*`)
- Colors (`c-*`, `bg-*`)
- Typography (`fs-*`, `txt-*`)
- Border radius (`rad-*`)
- Width utilities (`w-*`, `f-w`)

## 🚀 Installation

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A code editor (VS Code, Sublime Text, etc.) - for customization
- Basic knowledge of HTML/CSS - for modifications

### Steps

1. **Clone or Download the Repository**

   ```bash
   git clone https://github.com/yourusername/zero1-4th-project.git
   ```

   Or download as ZIP and extract.

2. **Navigate to Project Directory**

   ```bash
   cd zero1-4th-project
   ```

3. **Open in Browser**

   - Simply open `index.html` in your web browser
   - Or use a local development server:

   **Using VS Code Live Server:**
   - Install "Live Server" extension
   - Right-click on `index.html`
   - Select "Open with Live Server"

   **Using Python:**
   ```bash
   # Python 3
   python -m http.server 8000
   ```

   **Using Node.js:**
   ```bash
   npx http-server
   ```

4. **Access the Dashboard**

   Open your browser and navigate to:
   - Direct file: `file:///path/to/index.html`
   - Local server: `http://localhost:8000`

## 💻 Usage

### Navigation

- Click on sidebar menu items to navigate between pages
- All navigation links are functional and interconnected
- Use the search bar in the header for search functionality (UI only)
- Click the notification bell icon to view alerts (UI only)

### Responsive Behavior

- **Desktop (> 1024px)**: Full sidebar with labels
- **Tablet (768px - 1024px)**: Condensed sidebar
- **Mobile (< 768px)**: Collapsible sidebar, stacked layouts

### Customization Quick Start

1. **Change Colors**: Edit CSS variables in `main.css`
   ```css
   :root {
       --blue-color: #0075ff;
       --orange-color: #f59e0b;
       --green-color: #22c55e;
       --red-color: #f44336;
       --grey-color: #888;
   }
   ```

2. **Update Content**: Modify HTML files directly
3. **Add New Pages**: Follow the structure of existing pages in `html/` folder
4. **Modify Layout**: Adjust grid and flexbox classes in the framework

## 🎨 Customization

### Color Scheme

The project uses CSS custom properties for easy theme customization. Edit the `:root` section in [css/main.css](css/main.css):

```css
:root {
    --blue-color: #0075ff;        /* Primary color */
    --blue-alt-color: #0d69d5;    /* Primary hover/active */
    --orange-color: #f59e0b;      /* Warning/attention */
    --green-color: #22c55e;       /* Success states */
    --red-color: #f44336;         /* Errors/critical */
    --grey-color: #888;           /* Secondary text */
}
```

### Typography

Fonts are loaded from Google Fonts. To change fonts, update the `<link>` tags in HTML files and the `font-family` in CSS:

```css
body {
    font-family: "Your Font", sans-serif;
}
```

### Layout Adjustments

- **Sidebar Width**: Modify `.sidebar` class in `main.css`
- **Grid Layouts**: Adjust `grid-template-columns` in `.warpaber` class
- **Card Spacing**: Change `gap` property in grid containers
- **Responsive Breakpoints**: Edit media queries in `main.css`

### Adding New Components

1. Create HTML structure following existing patterns
2. Use utility classes from `framework.css`
3. Add custom styles to `main.css` if needed
4. Maintain consistent spacing and color usage
